## 尚未在本机执行

本机没有 Docker、PostgreSQL 和可用的 POSIX Shell。因而未执行真实 PG 行锁/并发/重启测试、Docker 构建或 Compose 启动、Caddy 配置验证、Shell 解释器检查、真实 pg_dump/pg_restore 演练。

已提供 `.github/workflows/production-checks.yml`：Ubuntu + PostgreSQL 17，执行原有测试与真实 PostgreSQL 迁移/对账/跨实例行锁/HTTP 幂等及竞争预约测试；另提供独立随机 Compose 项目的角色权限、备份恢复内容比对。CI 还包含 Shell 语法、Caddy validate 和容器构建。**本次未推送或触发该 CI，不能声称已绿灯。** CI 的临时测试凭据不是生产凭据。

人工运行真实数据库测试时，设置 `TEST_DATABASE_URL` 指向独立、名称以 `_test` 结尾的数据库，再在 server 运行 `npm run test:postgres`。测试只创建和清理自身随机 schema；绝不能指向在线库。缺少变量时该专用命令直接失败，不把跳过当通过。
