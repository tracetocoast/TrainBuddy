## 确认失败：排班权限（P1）

在独立临时数据库内，使用 `student_only` 演示身份的会话，向 `POST /api/v1/coaches/coach_001/exceptions` 提交未来的 `startAt`、`endAt`、`type: closed`、`reason`。预期 403，实际 200，并创建排班例外。

路由只有登录验证，服务没有验证操作者与教练归属。修复应要求有效教练角色及本人教练档案与路径一致，并回归本人、其他教练、学员、缺档案及非法时间等场景。此轮仅改造 UI，未修改后端规则；此问题修复前不能将真实预约服务视为可上线。
