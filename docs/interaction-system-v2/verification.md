## 原生模拟器 / 真机必须复核

每个用例记录设备型号、系统版本、基础库、网络条件、分支提交、输入、截图/录屏与实际响应。下列是验收要求，未执行项不打勾。

| 用例 | 操作 | 客观通过条件 |
| --- | --- | --- |
| A1 数值编辑 | 教练打开其可编辑草稿，输入 52.35 kg、6 次；快速连点十次加减；调组数至 1/30 | 最终值精确、不越界；编辑时无 HTTP；保存后逐组值一致 |
| A2 不同组目标 | 第 1/2 组设为 50×5、45×8；复制组、排序动作并保存发布 | 新 ID 唯一；各组值不混淆；已进行会话仍保留旧快照 |
| A3 缩减/退出 | 将 4 组减为 2 后取消；输入未保存参数后返回再进入；制造 revision 冲突 | 取消仍显示 4 组；原输入恢复；冲突禁止发布且本地内容保留 |
| B1 日期切换 | 从日期条和日期 picker 快速切换；慢网下交错响应 | 时间选项属于最后选中日期；旧数据不可提交；加载/失败可见 |
| B2 无效时间 | 选择已过去、已关闭、他人已约时段；另一客户端抢占后提交 | 无效项不可选；竞争由真实 API 拒绝后重载、重新确认，无假成功 |
| C1 提交状态 | 快速双击确认；成功时检查真实返回 status | 仅一在途请求；pending 显示已提交待确认，confirmed 才显示成功 |
| C2 不确定网络结果 | 请求发出后断网，恢复后重试 | 使用相同幂等键；没有重复预约；错误文本可见；可重载预约列表核对 |
