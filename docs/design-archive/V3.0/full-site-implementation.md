## 接手与回滚
新电脑先按开发接手指南安装依赖和启动本地API，再导入项目编译。密钥、本机AppID/工具配置和本地数据库不会随提交迁移。不要运行reset清除既有数据。
本次为独立功能提交，可通过`git revert <功能提交SHA>`回滚；合并提交不要盲目整体回滚，以免撤销协作者工作。
