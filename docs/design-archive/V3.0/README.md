# Field Notes V3.0 第一阶段

2026-11-14。远端 main 为 `0a1a941`，实施基线为包含 V1.27 本地提交的 `1eff383`，工作分支为 `feat/field-notes-v3`。七张 PNG 和逐页说明定义视觉验收，设计包中的示意数据仅供理解页面状态。

| 图 | 对应源码与可复用实现 | 视觉和交互差异 | 重点回归 |
|---|---|---|---|
| 01 学员首页 | `pages/home`、`components/bottom-nav` | 统计及快捷入口下沉，以课程、恢复训练、最近报告为主。按原稿保留一张照片的位置。 | 无课程与无草稿路径、教练首页不受影响 |
| 02 教练录音 | `pages/record`、`components/voice-input`、`utils/speechComposer` | 通用录入块换成衬线标题、身份行、语音/手动切换、中央控制与转写区。 | 已选学员、连续录音、真实暂停与授权降级 |
| 03 AI 整理 | `pages/record` 的核对状态、现有候选与冲突控件 | 把卡片化核对变成三项摘要、动作列表、公开反馈和核对入口。 | 冲突保留人工值、明确确认后才发布 |
| 04 训练执行 | `pages/workout` 的 Session、组菜单和保存队列 | 改为日期和标题、进度线、展开表格、折叠动作、底部休息条。 | 原位数字键盘、未知重量、失败重试、结束和撤销 |
| 05 动作库 | `pages/exercises` 的搜索、历史排序和多选 | 以常用、最近和全目录切换取代首屏大图块；保留筛选。 | 选中状态跨筛选保持、追加只提交一次 |
| 06 学员报告 | `pages/training-report`、`utils/trainingReport` | 报告先给标题与摘要，逐组明细下沉，公开反馈单独排版。 | 已发布和所有权检查、缺失指标不推断 |
| 07 进展 | `pages/growth` 的月历、分类和当天列表 | 月历移到首要位置，指标弱化，日期记录直接打开报告。 | 同日多训练、月份切换、分类与权限 |

后续已按用户要求扩大实施范围；当前实际完成与未验收部分以 [实施记录](full-site-implementation.md) 为准。本文保留最初设计映射，不代表全站验收通过。
