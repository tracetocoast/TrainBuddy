## 落地范围

- 每日记录饮食区同时提供手写添加和拍照记饮食；拍照页带上当前日记日期，从日记进入时可返回手写。
- 饮食列表按来源标注「手写」或「拍照估算」；拍照记录展示碳水／蛋白／脂肪，未知为 —。
- 学员底栏选中图标改为教练同款松绿 `#28744e`，选中底为 `--surface-raised`。
- 出勤请求幂等键为 `att_<预约ID>_<status>`，请求体只保留 status 与 note。
- 约课页 `padding-bottom` 提高到 180rpx + 安全区；进展页训练记录不再显示 ›。
