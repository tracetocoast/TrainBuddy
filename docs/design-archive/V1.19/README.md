# V1.19 设计与实施归档

2026-11-07。训练计划列表、首页快捷入口和约课页沿用现有卡片，不另出线框。本版调整计划操作入口、左滑手势和约课深色态。

- [版本更新](../../releases/V1.19.md)

## 落地范围

- 计划卡片点击为只读详情；编辑、删除只出现在左滑操作区。开练按钮右对齐。
- 左滑使用页面级 WXS：`bindtouchmove` 默认可竖滑，仅横滑时 `return false`。
- 首页「开始训练」进入记录（训练执行）页。
- 约课确认按钮共享页面皮肤变量；我的预约取最近 5 条降序。
