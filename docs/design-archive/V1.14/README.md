## 落地范围

- 计划列表：新建、作者左滑删除、全部 / 教练 / 我的。
- 计划编辑：只保留名称；日期为永久、长期时段或每周 / 每月固定日；动作从动作库加入。
- 记录页：永久及当天开放的计划可开始训练；开练后可返回计划列表。
- 摩天轮：去掉会话中的配置模板和日记入口；卡片与锁定页使用动作库示范图。
- 锁定执行：完成本组与跳过在底部栏左右并排；组歇只留一个进入下一组按钮。
