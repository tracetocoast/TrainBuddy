# V1.6 · 连续分类浏览

基线：760f258839b96e3f1eb28598c26fc42edd6f986b。沿用 V1.5 布局与视觉。

## 改动与交互

原来单个部位结束即显示全部结果，需要手动切换。现在按接口返回的部位顺序连续追加，每段展示名称和实际 total。短分类自动补满视口，分页请求互斥，失败保留已加载内容并允许重试。

`bodyPart/list/page` 始终指向末尾加载分类；`sectionHistory` 保存此前各段；`activeBodyPart` 仅表示视口当前分类。不能用视口分类覆盖分页查询。点击已加载分类只定位，不重新请求。搜索和器械变化重新建立结果流；有关键词时不跨分类。全部动作保持普通分页，避免重复展示。
