# V1.7 设计与实施归档

2026-11-05。视觉沿用暖白自然绿与 [V1.4](../V1.4/README.md) 基础令牌，不新出完整线框。参考常见健康 App 的目标环与周柱结构，但未照搬第三方界面。

## 实际落地

- 成长页：本周目标环、归一周柱、日历标记与当日摘要、近期最高负荷（仅真实 `actualWeight/actualReps`）。
- 身体数据：图表统计改为当前 / 上次 / 变化；单指标页同步；空态不造曲线。
- 展示层归一周柱高度；服务端 `bars[].sets` 与 `height` 口径未改。
- 日历「日记状态」仍来自 diary markers；「身体测量」点位由成长页合并 `/body-measurements` 日期。
