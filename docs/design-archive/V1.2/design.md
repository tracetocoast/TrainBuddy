# V1.2 前端设计与组件映射

核心布局沿用 V1.1 的三导航。教练：工作台／学员／日程；学员：课程／记录／进展。账户及身份切换继续从首页头像进入。

## Refined Green

背景 #FAFBF7，表面 #FFFFFF，主文字 #25352C，辅助文字 #6E7C72，强调 #28744E，边框 #E0E7DC，录音及错误 #B42332。保留全局旧 Token，仅新增语义别名；教练按钮和卡片精修限定在 coach-scope。

页面边距沿用 32rpx，分区约 24–32rpx；卡片 20rpx，控件 14rpx；主标题 44rpx、分区标题 29rpx、输入 28–30rpx。数字使用等宽变体。主要操作最小 44px；必要宽度显式覆盖原生 button 的默认宽度，避免变成半宽胶囊。页面不使用装饰玻璃、渐变或 Emoji 图标。

## 页面与任务

| 页面 | 结构及交互 | 原入口与业务约束 |
| --- | --- | --- |
| 工作台 | 日期与头像 → 唯一麦克风主入口 → 今日课程 → 两个辅助入口 | goRecord 仍先选学员，不自动录音；课程用真实状态 |
| 记录 | 学员上下文 → 四个同页任务分区 → 保存反馈 | hidden 切换保留原话与候选；活跃录音或处理中不能跳区；最终确认不改 pending 组完成规则 |
| 核对 | 原话按需展开，候选逐项确认；冲突和缺失项可见 | 保留补齐、三种合并及撤销；不自动认定 AI 结果正确 |
| 训练表 | 紧凑动作与逐组参数；公开建议与私人备注分开 | 手动动作库折叠；私人备注仍默认折叠；最后输入先保存后同步 |
| 学员 | 搜索＋平面名单＋档案入口 | 诊断仅 develop 且 query diagnostics=1 时可见，不替代服务端鉴权 |
| 日程 | 默认日视图、横向日期、课程行、低频设置 | 保留周视图、待处理和原冲突规则；开放时段按需查看 |

## 组件与动效

- `components/voice-input/`：纯原生展示组件，接收状态、文本、秒数、权限和暂停能力，通过事件调用现有页面控制器。两处录入共享原录音互斥机制，不改 speechComposer、ASR 或 Prompt。
- `components/ui-icon/`：原创 1.7px 线条 SVG 图标，构建时编码为本地图片数据，不依赖 DOM；生成脚本为 scripts/generate-coach-icons.cjs。
- `styles/coach.wxss`：只作用教练页面；共享 base.wxss 与原学员内容流程保留。
- 录音点仅在真实 recording 状态呼吸；加载转圈只表示真实等待，不表达进度。减少动画偏好及系统媒体查询关闭动画，保留状态文字。
- 没有暂停能力时，仅保留一个“结束本段”，结束后可继续补录；不伪造暂停能力。

## 错误与边界

未绑定、未选择学员、草稿读取失败、搜索无结果、无课程及加载分别处理。已完成记录必须查最新状态再显示只读；不因旧创建快照提供假编辑入口。创建流程不能产生新的本次记录时，明确说明接口/流程限制，不能通过前端伪造 sessionId。

现有单页过长问题通过任务分区减少同时可见内容；没有增加新路由或强制四次提交。320px、长姓名、长动作、20 动作、软键盘及真机中断仍须实测，媒体查询和 cursor-spacing 只能作为适配实现，不能当作通过证据。
