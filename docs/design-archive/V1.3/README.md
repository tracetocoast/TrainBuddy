## 实际实现与边界

视觉继续使用 Refined Green。学员详情的训练历史通过既有 listSessions 读取，计划入口复用原计划页；不把未授权资料变成可见。生活资料仅折叠展示，原服务端权限和数据来源不变。个人中心按角色隐藏不相关菜单；体态直达复用原上传与分析事件，不传入其他学员 ownerId，也不自动共享照片或报告。

候选修改保持原字段与合并语义，改为带标签的常规输入区，缺失字段可读；多位数字输入不再因第一位有效值而收起。无效组次维持待确认。训练表逐组字段及完成按钮保留，发布前展示具体 pending 组；原自动标完成规则没有改变。

工作台使用真实 pending 数量直达待处理页，没有增加虚构草稿待办。现有列表接口会过滤其他学员的未共享草稿，因此本轮不假装能够完整恢复教练草稿。schedule-rules 的固定演示操作仅在 develop 且 query demo=1 时可用；正式日期/星期、时段、课时、缓冲与冲突核对编辑器仅提出方案，未伪装成已完成。
