# 教练导航与个人中心调整

移除所有页面的双角色选择框，角色切换集中到个人中心。仅当服务器已经授予另一角色时显示切换入口；实际切换仍使用现有权限检查及会话持久化，学员视角恢复本人数据对象，随后返回首页。

修正底部“个人”原来指向 AI 页的问题。教练导航为：首页、排课、学员、成长、个人。学员导航保留首页、约课、训练、成长，并将个人正确指向个人中心。教练课后记录继续可从首页进入，并在成长页提供入口。

成长页提供拍照记饮食、体态分析、阶段目标预览三个专属工具入口，直接打开既有工具页对应选项，不复制工具业务逻辑。AI 工具页的导航归属成长；未配置供应商的提示和演示标记保留。

个人中心主要展示昵称、账号 ID、当前身份、按角色显示的服务关系或教练邀请码，以及隐私设置和退出登录。训练日记、动作库等功能入口移至成长页。仅调整前端，不修改后端权限、业务数据或供应商配置。

验证：145/145 自动化回归通过，包含所有路由无角色框、双角色导航、工具直达与个人身份切换授权测试；官方 33 WXML、38 WXSS 编译通过。手机真机视觉和触控未执行，不能作为已通过事项。
