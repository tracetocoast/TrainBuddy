# 前端简化与协作说明

日期：2026-10-21。前端分支：`hyy_release`；AI 分支：`srz_release`；集成分支：`main`。

## 2026-10-22 品牌与全局主题更新（当前视觉）

根据用户最新要求，以 AI 助手为全局视觉基准，替代下方旧版白底、荧光绿与卡通壶铃方向。原有信息架构、业务数据与操作行为继续保留。

- 品牌标志采用双环相扣的独立矢量图形，表达训练搭档与连接。源文件为 `miniprogram/assets/brand-logo.svg`，通过统一 `brand-logo` 组件呈现，覆盖首页、AI、登录和各品牌栏。
- 底色 `#111b26`，正文 `#e4edf3`，次要正文 `#91a6b6`，卡片 `#192a38` / 深蓝灰渐变，细边框 `#304351`，银蓝强调色 `#c6d7e3`。
- 主操作采用银色按钮与深色文字；次操作使用深色底、细边框与浅色文字，移除绿色和按钮厚底阴影。
- 首页移除卡通壶铃，以品牌标志作为克制的视觉点；成长摘要、约课、逐组记录、动作库、日记、账户与身体记录统一主题。
- 身体数据页继续沿用用户参考图中的人体标注、数据/图表/日历层级与左右独立记录，仅同步到深色视觉体系。
- 底部导航用同一套本地矢量细线图标替换字符符号；导航栏、安全区域和角色切换同步深色。
- `button` 明确继承文字颜色，避免微信原生按钮将卡片标题重置成黑色；禁用、录音和警告状态保留可辨识样式。

验证：64 项回归测试通过，26 个 WXML 和 28 个 WXSS 通过微信官方编译器，JavaScript / JSON 校验通过；新 Logo 所在页面均已注册组件。模拟器已确认新版首页、Logo、主按钮和导航显示正常。真机字号和系统控件仍需后续复查。

本轮不修改 AI 服务端和业务接口。与 `srz_release` 合并时需逐文件处理共用样式、AI 页头和品牌组件，保留若芷的供应商与运行配置变更。

## 设计方向

参考多邻国清晰的主操作、轻快的鼓励语气、圆角描边与按钮底部厚度，保留练搭子的健身业务和独立图形。首页壶铃表情使用本地 WXML / WXSS 绘制，不依赖图片服务。

参考资料：

- https://blog.duolingo.com/new-duolingo-home-screen-design/
- https://blog.duolingo.com/hub/design/

本次视觉方向替代功能设计文档第 22 节原先的荧光绿与深色首页方向；业务规则继续沿用原文档。

## 页面变化

| 范围 | 调整 |
| --- | --- |
| 基础样式 | 白底、绿色主色、浅灰描边；统一字号、间距、输入框高度和按钮状态；支持底部安全区域 |
| 学员首页 | 一个开始训练主按钮；接下来的课程、三个真实统计、日记和动作库；移除写死的周次、星期、下肢任务和无数据的力量进步 |
| 教练首页 | 待确认预约与绑定学员；学员档案、记录训练；不将绑定名单包装为今日课程 |
| 角色切换 | 仅拥有多个角色时展示；单角色用户在个人中心申请其他身份 |
| 底部导航 | 保留现有目的地，调整选中态、尺寸、安全区域；AI 入口保留 |
| 约课与训练 | 缩短标题，减少开发术语，保留预约确认、逐组录入、结束与放弃等现有行为 |
| 成长 | 本周次数、训练天数、完成率、连续记录；保留日历和记录；删除无依据的力量进步占位卡片 |
| 登录与个人中心 | 两个主要体验身份、清楚的体验版说明；权限拒绝用例继续由自动化测试覆盖 |
| 日记、计划、课后记录 | 沿用共用样式，统一局部配色与输入框，不改业务接口 |

连续记录只使用 `diaryStreak`，不再用训练天数冒充连续天数。没有数据使用「—」，不生成模拟进步。

## 视觉约定

- 主要绿色 `#58cc02`，按钮正文深绿 `#244b11`；背景 `#ffffff`，正文 `#3c3c3c`，次要正文 `#777777`，边框 `#e5e5e5`。
- 页面水平留白 32 rpx；标题 44 rpx；段落 25–28 rpx；主要按钮至少 88 rpx。
- 每块内容突出一个主操作；次要操作使用白底描边或蓝色文字。
- 不展示接口名、用例编号、版本索引等开发信息作为主要产品引导。
- 不在本轮添加虚构积分、连续训练奖励、达标预测或 AI 成功状态。

## 分支协作与合并

两个人分别在 `hyy_release`、`srz_release` 开发，通过 Pull Request 合入 `main`，完成相关检查后由另一人审阅。每次新任务开始前更新本地远程状态，合并后将最新 `main` 同步回各自分支；不要强制覆盖伙伴分支。

本轮没有修改 `server/`、AI 页面文件、AI 服务、运行配置 `miniprogram/config.js`。`project.config.json` 是原有的本机微信工具修改，不属于这轮前端版本。

检查发现 `srz_release` 的 `010e9da` 已含布局修复和局域网 API 配置。未来合并时，共用的 `app.wxss`、导航与角色组件，以及首页、约课、登录、个人中心的样式可能产生冲突。应保留本轮视觉方向与原生按钮尺寸修复，同时保留若芷的 AI、服务监听和局域网地址逻辑；逐文件合并，不能直接用整条分支覆盖另一条。
