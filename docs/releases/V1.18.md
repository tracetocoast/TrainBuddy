# V1.18 · 首页更名与切页底色

2026-11-07 · 尚未提交 · [设计与实施归档](../design-archive/V1.18/README.md)

## 改造点

1. 学员底部导航「课程」改为「首页」。今日训练里的最近训练摘要已去掉。
2. 首页本周训练下方每天展示一句中英对照名言，同一天打开保持同一句。
3. 进展页左上角标志和「练搭子」不再叠在一起。
4. 原生窗口底色跟随当前皮肤：白色用纸色，黑色用深绿底。切 Tab 前和新页加载时同步导航栏与窗口色。

## 验证

- `node --test test/coach-navigation.test.js test/coach-refinement.test.js test/ui-rollout-page.test.js` 覆盖导航文案、每日名言和原生底色。
- 微信开发者工具需重新编译后，用学员账号看首页名言、进展页品牌栏，并用黑白皮肤切底部导航。本机未跑官方编译，真机未验收。
