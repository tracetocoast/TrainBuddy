# V1.7 · 成长页与身体数据展示优化

2026-11-05 · 代码提交见本版合并记录 · [设计与验收归档](../design-archive/V1.7/README.md)

1. 成长页增加本周训练目标环形进度；周柱状图按本周最大组数归一，零值保留底座。
2. 日历区分训练、主动休息、饮食、日记状态与身体测量；无记录日期不再误标为休息。
3. 有真实负荷数据时展示「近期最高负荷」卡片；身体数据入口优先排列。
4. 身体数据趋势明确展示当前值、上次值与变化量；用升降文案表达，不以红绿代表好坏。
5. 记录不足时不生成模拟曲线；`bodyInsights` 统计口径保持不变。

验证：相关页面路由与 ui-rollout 用例通过；已为演示账号陈佳宁写入身体测量样例便于看图。Mac 上未跑微信官方 wcc；真机流畅度未验收。
