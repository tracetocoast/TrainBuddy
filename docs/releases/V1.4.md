# V1.4 · 学员动作库接入公开目录

2026-11-04 · 代码提交见本版合并记录 · [设计与验收归档](../design-archive/V1.4/README.md)

1. 将 free-exercise-db（Unlicense）800+ 动作导入练搭子公开动作库。
2. 列表支持搜索、部位/器械筛选与分页；详情展示 jsDelivr 示范图和步骤。
3. 未审核与自定义动作不进入学员教学列表；本批种子统一标记已审核。
4. 「加入计划」继续写入现有个人草稿，不重做训练编排器。
5. 种子按 sourceId 幂等导入；历史训练仍使用 nameSnapshot。
6. 去掉原先 5 个中文精选示例；名称与步骤以中文展示，英文原名保留供搜索。
7. 步骤说明改为离线映射文件 `exercise-instructions-zh.json`（按 sourceId）；详情优先读映射，缺失才回退规则翻译。
8. 统一基础样式令牌（按钮/卡片/状态标签/减动效）；首页学员与教练工作台按真实统计与预约状态重排信息层级。

验证：服务端相关动作库/计划/训练用例通过；873 条 sourceId 均已写入映射（其中 5 条源数据本无步骤）；首页相关 ui-rollout 用例通过。Mac 上未跑微信官方 wcc 编译器。jsDelivr 图片 URL 会 301 到 GitHub raw，开发者工具需勾选不校验合法域名；真机与正式 download 域名未验收。
