# V1.22 · 自主训练与组编辑

2026-11-08 · [设计归档](../design-archive/record-redesign-draft/README.md)

1. 新建训练使用独立入口页，自行添加动作直接创建或恢复空白训练，保留动作轮盘。
2. 训练组改为紧凑数值与方框完成按钮；底部面板编辑重量、次数和热身/正式组，不跳页；移除执行页大幅插画。
3. 支持增删训练组、移除动作及倒序动作历史，完成状态由实际接口结果驱动。
4. 模板编辑移除日期、有效期和频率；动作库增加真实训练次数与常用动作推荐排序。
5. 包含过期会话 401 处理与 WXS 编译检查修复。

验证：15 项专项测试通过。此前全量 230 项中 10 项失败，其中一项测试替身已修复，其余尚待复核；真机未验收。本次为阶段提交。本机配置、密钥和数据不纳入提交。
