# V1.1 · 教练工作台与训练录入优化

日期：2026-11-03 · 代码提交：`4671ab6`（包含 `a63d1b6`、`074762c`）

设计文档：[V1.1 设计归档](../design-archive/V1.1/README.md)。

1. 教练端导航调整为「工作台、学员、日程」，首页突出训练记录和今日课程。
2. 学员端导航调整为「课程、记录、进展」，首页集中展示课程与教练反馈。
3. 身份切换统一放到个人页，体态评估、邀请学员保留为次级入口。
4. 语音录入改为点击开始／结束，支持通道允许的暂停续录；识别结果核对后加入训练表。
5. 动作库默认折叠；完善训练字段保存、失败重试和同步前校验。
6. 修复本地 API 连接配置、批量预约中断及排班权限校验问题。

验证：151 项测试通过，微信原生编译通过，已同步开发者工具；真机录音及真实语音服务待验证。此记录不代表正式上线。
