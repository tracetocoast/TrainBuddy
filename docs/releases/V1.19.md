# V1.19 · 计划左滑与约课收尾

2026-11-07 · 尚未提交 · [设计与实施归档](../design-archive/V1.19/README.md)

## 改造点

1. 训练计划去掉「创建默认下肢计划」。「开练」靠右；「编辑」放到左滑后的垃圾桶左侧。点卡片进入只读详情，左滑「编辑」才可改。
2. 计划列表左滑删除与页面上下滚动分开处理：不再用 `catchtouchmove` 接管整次手势，确认横滑后才锁滚动。
3. 首页快捷入口「开始训练」跳到记录页。
4. 约课深色模式下「确认预约」跟皮肤绿色，四字居中不换行；可选时段颜色限制在卡片内。「我的预约」按开始时间从新到旧，只显示最近 5 条。

## 验证

- `node --test test/plan-list-page.test.js test/plan-editor-page.test.js test/ui-rollout-page.test.js test/interaction-system.test.js` 覆盖只读详情、左滑开合、开始训练跳转、预约排序和确认按钮样式。其中训练执行页既有用例仍有失败，与本版无关。
- 微信开发者工具需重新编译后，用学员账号看计划左滑、上下翻页、只读详情，并用黑色皮肤看约课确认按钮和时段卡片。本机未跑官方编译，真机未验收。
