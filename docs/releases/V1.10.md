# V1.10 · 约课与教练日程 UI 优化

2026-11-05 · 代码提交见本版合并记录 · [设计与验收归档](../design-archive/V1.10/README.md)

1. 学员约课强化日期态：今天、已选、已加载可约／满或无可约；选中日期另有「已选」文案。
2. 可选时段改为统一时间按钮网格；已选同时用边框、勾选文案与标记表达，不单靠颜色。
3. 预约摘要突出教练、日期、时段与数量；仍走原有确认弹层与提交，仅服务端成功后提示成功。
4. 教练日视图按时间轴排列课程，标注即将开始／进行中；状态标签统一 `statusTone`；周视图可点进日视图并显示真实待确认数。
5. 加载中有明确提示；失败保留选择并可重试；改期选时段同步强化日期与时段反馈。

验证：未改预约状态机、可约计算、冲突校验、权限与接口；相关页面绑定用例通过；Mac 上未跑微信官方 wcc。
