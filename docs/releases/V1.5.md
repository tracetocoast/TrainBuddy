# V1.5 · 动作库分类浏览优化

2026-11-05 · 基线 `e1279a9` · [设计与验收归档](../design-archive/V1.5/README.md)

1. 动作库改为左侧部位分类、顶部器械筛选、右侧双列图文卡片。
2. 搜索与筛选固定可见，分类和结果独立滚动，减少整页反复滑动。
3. 返回动作库保留结果与位置；切换筛选回到列表顶部，继续使用原分页接口。
4. 增加图片失败占位、分类重试与分页重试，防止旧搜索结果覆盖新筛选。

173 项测试、35 WXML/41 WXSS 编译通过，已同步微信工具；真实手机、小屏与弱网仍待验证。未新增虚假的精选、常用次数或拍照识别入口，详情及加入计划规则不变。
