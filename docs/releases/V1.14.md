# V1.14 · 学员自建计划与训练执行收尾

2026-11-07 · 对应提交 `0601229` · [设计与实施归档](../design-archive/V1.14/README.md)

## 改造点

1. 学员可以新建、编辑自己的训练计划，并在计划列表左滑删除自己创建的计划；列表改为「全部计划 / 教练计划 / 我的计划」。
2. 编辑页去掉目标和调整说明。名称可选以前用过的计划名，也可点「自定义」输入。训练日期支持永久、长期时段、每周几或每月几号。
3. 添加动作改为动作库：常用位只显示最近用过的动作库动作，最多 5 个，不够不凑预设动作；更多动作去动作库勾选后返回。
4. 永久计划只要没被删除，记录页「可执行计划」里随时可以开始训练。同一计划当天完成后仍不能再开一次。
5. 开练后左上角可返回计划列表，训练会保留。摩天轮页去掉「配置训练模板」和「日记记录」；卡片和具体训练页使用动作库示范图。
6. 具体训练页去掉卡片里的完成本组、沿用上一组和跳过。底栏左右并排：左「跳过」、右「完成本组」。组歇只保留「直接进入下一组」。

## 验证

- `node --test` 已通过计划编辑、日程开练、动作库和首页相关测试。补充覆盖：旧计划日期在过去时，改成永久或每周后仍可发布。
- 微信开发者工具需重新编译后，用学员账号核对：自建计划、永久开练、返回、示范图和底栏按钮。本机未跑官方编译，真机未验收。
