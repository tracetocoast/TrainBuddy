# V1.29 · 训练执行改回摩天轮选动作

2026-11-18。对应实现为本文件所在提交。[设计与实施归档](../design-archive/V1.29/README.md)

1. 开始或继续训练后，先用左右滑动或点选的动作卡片选择本次要练的动作。
2. 选中卡片放大后，点「开始此动作」才进入该动作的组记录。
3. 执行中返回，或当前动作记完后点「选择下一个动作」，都会回到卡片选择。
4. 训练首页的继续训练、待练计划和历史折叠保持不变；组记录仍是原位输入。
