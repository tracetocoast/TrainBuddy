# V1.17 · 进展页收尾

2026-11-07 · 尚未提交 · [设计与实施归档](../design-archive/V1.17/README.md)

## 改造点

1. 进展页底部预留底栏高度，滑到底时入口不再被挡住。「每日日记」和「动作库」改为左右并排。
2. 训练日历可切换月份。日期详情里不能跳转的箭头已去掉；训练名称和「X 组完成」同一行左右排布。
3. 进展页字号与课程、记录页对齐。训练节奏、近期训练亮点、训练日历、训练记录、记录与学习下的说明小字已去掉。
4. 日记里当天训练同样把「X 组完成」放到名称右侧。

- `node --test test/coach-navigation.test.js test/ac-diary.test.js` 覆盖日历换月与日记相关接口。
