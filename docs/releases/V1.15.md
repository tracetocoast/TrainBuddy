# V1.15 · 运营角色与后台

2026-11-07 · 对应提交 `dd185b4` · [设计与实施归档](../design-archive/V1.15/README.md)

## 改造点

1. 用户角色增加可登录的运营身份。演示账号为「运营 · 平台运营」；学员和教练不能自行领取该角色。
2. 运营登录小程序后只看到后台地址和复制、退出，不进入学员或教练页面。
3. 浏览器 `/ops/` 可查看和管理账号、教练审核、权益、AI 任务和通知。停用后无法登录，启用后恢复；不能停用当前运营本人。
4. 学员提交的教练申请会留下待审记录。拒绝不授予教练角色，通过后才授予。

## 验证

- `node --test test/ops-admin.test.js` 覆盖权限、审核、停用恢复，以及任务列表不返回结果正文。
- 微信开发者工具需重新编译后，用运营演示账号确认只进入提示页。本机未跑官方编译，真机未验收。
