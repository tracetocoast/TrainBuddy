# V1.20 · 日记拍照记饮食与出勤幂等

2026-11-08 · 对应提交见本版合并记录 · [设计与实施归档](../design-archive/V1.20/README.md)

## 改造点

1. 约课页底部加高，避免底栏挡住「我的预约」。进展页训练记录去掉右侧 ›。
2. 教练「开始上课」和「确认结束」使用不同幂等键（按出勤状态区分），同一动作重试仍安全。
3. 学员底栏选中色与教练端对齐，改为同一套松绿。
4. 每日记录饮食区增加「拍照记饮食」；列表展示 AI 估算宏量，并标注手写 / 拍照来源。
5. 手写与拍照两种记法文案统一：拍照结果为估算，确认后才会写入。

## 验证

- `node --test test/booking-attendance.test.js test/coach-navigation.test.js test/coach-refinement.test.js test/ui-rollout-page.test.js` 覆盖出勤幂等键、底栏选中绿、约课底部留白、进展页记录无 ›、日记拍照入口与来源标签。
- 微信开发者工具需重新编译后，用学员账号看底栏选中色、约课滚到底、日记拍照入口；用教练账号走开始上课再确认结束。本机未跑官方编译，真机未验收。
