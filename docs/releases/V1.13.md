# V1.13 · 皮肤系统（白色 / 黑色）

2026-11-06 · 代码提交见本版合并记录 · [设计与实施归档](../design-archive/V1.13/README.md)

1. 新增双皮肤系统：白色（默认，外观与现状完全一致）与黑色（墨绿暗色），在「个人中心 → 外观」切换，选择本地持久化。
2. 全站样式 token 化：页面与组件约 400 处硬编码色值替换为语义 CSS 变量；浅色值与原值一致，白色皮肤外观不变。
3. 新增 `styles/skin-dark.wxss`（`.skin-dark` 作用域覆盖全部 token）与 `utils/theme.js`（皮肤状态、导航栏/窗口底色同步）。
4. `app.js` 包装全局 `Page()`，onShow 自动注入 `skinClass` 并同步导航栏颜色；页面根节点绑定 `{{skinClass}}`，页面 JS 无需单独接入。
5. 切换皮肤带 circle-blur 动效：新皮肤底色圆从点击处扩散（blur 软边）盖住全屏后换肤再淡出，模拟 Web View Transitions 的 circle-blur-reveal；开关为滑块式分段控件。
6. 本版基于上游 V1.12 合并落地：为上游 V1.6-V1.12 新增的亚麻纸/薄荷/松绿/玫瑰色板与玻璃底补齐 token 及暗色映射，`bottom-nav` 在 7 个页面移入根 view，修复 workout 页 2 处自引用 token。

验证：全部 WXSS 花括号配对 0 错误；残留硬编码色值仅 growth 页 1 处琥珀分类色（有意保留）。基于原仓库 V1.12 合并，上游样式重构（`--ix-*` 别名化）与皮肤体系兼容。官方 wcc/wcsc 编译与真机黑色皮肤目测验收未完成（本机未安装微信开发者工具）。

注：版本号原为 V1.5，因原仓库已独立使用 V1.5（动作库浏览改版），按编号顺序调整为 V1.13。
