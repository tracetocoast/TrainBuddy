# V1.8 · AI 页面体验优化

2026-11-05 · 代码提交见本版合并记录 · [设计与验收归档](../design-archive/V1.8/README.md)

1. AI 工具入口改为三列图标卡片网格，突出名称、用途与可执行操作，去掉长段滑动说明。
2. 体态分析展示真实照片预览与准备／分析中／完成／失败状态；失败展示接口原因与重试；报告仅展示已有分项，不伪造总分或骨架。
3. 饮食识别突出食物照片；营养卡片区分估算值、未知（—）与真实零值；确认／编辑／保存流程不变。
4. 目标图节点按真实任务状态着色，加载与失败可视化；不伪造进度百分比。
5. 轻量进入与状态动效，支持「减少动态效果」与系统减少动态偏好。
